# M-Pesa prize wheel clone

## Run locally

- Install dependencies with `npm install`.
- Start the development preview with `npm run dev`.
- Create a production build with `npm run build`.

The app is a Portuguese-language, single-page recreation of the supplied prize-wheel site. It uses local copies of the source page's stylesheet, favicon, Mozambican banknote images, and flag image.

## Important behavior

- The wheel and result dialogs are client-side only; this project does not process payments or issue prizes.
- The registration button opens the third-party affiliate destination used by the source site.
